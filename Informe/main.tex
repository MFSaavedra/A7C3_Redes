% El cuerpo del informe se compone en una sola fuente: no se usa monoespaciado,
% negrita ni cursiva para destacar nombres de archivo, comandos ni equipos.
% La tipografía solo cambia en los bloques de salida, que reproducen salidas y
% configuraciones literales de los routers. Las macros se conservan como marcas
% semánticas y no producen ningún cambio visual. \code solo permite cortar la
% línea después de cada guion bajo, porque los nombres largos, como
% R1_nombre_del_grupo, no se pueden dividir en sílabas y se salen del margen.
\newcommand{\codeunderscore}{\textunderscore\allowbreak}
\newcommand{\code}[1]{{\let\_\codeunderscore#1}}     % comandos, archivos y nombres de equipos (show ip bgp, R1_grupo)
\newcommand{\field}[1]{#1}    % atributos BGP y campos de las tablas (AS-path, next hop)

% BLOQUES DE SALIDA
% Las salidas de Quagga y las configuraciones se componen con listings, que corta
% las líneas largas en un espacio y marca la continuación con una flecha. Aparte
% de eso equivalen a un verbatim.
\lstdefinestyle{salida}{
	aboveskip=0.6em,
	basicstyle=\ttfamily\footnotesize,
	belowskip=0.6em,
	breakatwhitespace=true,
	breakindent=1.5em,
	breaklines=true,
	columns=fixed,
	frame=none,
	keepspaces=true,
	numbers=none,
	postbreak=\mbox{\textcolor{gray}{$\hookrightarrow$}\space},
	showstringspaces=false
}
% Con columns=fixed cada carácter ocupa una columna de ancho basewidth, que se
% mide al iniciar cada bloque como el ancho de un dígito en la fuente del bloque.
% Así las columnas de show ip bgp y show ip route quedan alineadas.
\newlength{\salidachar}
\lstnewenvironment{salida}[1][]{\settowidth{\salidachar}{\ttfamily\footnotesize 0}\lstset{style=salida,basewidth=\salidachar,#1}}{}

\section{Grupo y convenciones}
% Paso 1.
El grupo se llama \pendiente{nombre del grupo}. Todos los equipos virtuales llevan ese nombre como sufijo: el router R0 se llama \code{R0\_}\pendiente{grupo}, el computador PC1 se llama \code{PC1\_}\pendiente{grupo}, y así con el resto.

Einar se ejecutó como máquina virtual en VirtualBox, a partir de la imagen \code{einar1.0.iso} entregada por el curso: Linux 32 bits, sin disco virtual. Los routers de Einar usan Quagga 0.99.3, cuya consola sigue la sintaxis de Cisco.

   match ip address prefix-list salida
